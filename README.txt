KATALOG PRODUK - DEMO PAMERAN KKN

Jalankan:
- Buka index.html di browser.

Ganti data produk:
- Edit array "products" di script.js.
- images: ["images/foto1.jpg", "images/foto2.jpg"] untuk banyak foto.
- description dapat berisi teks panjang dan beberapa paragraf.

GitHub Pages:
1. Buat repository baru.
2. Upload semua isi folder ini.
3. Settings > Pages.
4. Deploy from a branch > main > /(root).
5. Save.
